このページについて

  • 日付は GitHub 上でマージされた日（UTC）。
  • 「作成から N 日」は、書かれてからマージされるまで開いていた期間。長いものは他の作業を先に通していたか、衝突の解消が必要だったもの。
  • 区切りと一行要約は後から付けた解釈で、それ以外の数値はすべて生成時に計測している。
