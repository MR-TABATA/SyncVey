準備完了です

以下の手順に従って SyncVey を起動してください。

1

リポジトリをクローン

GitHub からリポジトリを取得します。

git clone https://github.com/MR-TABATA/SyncVey.git cd SyncVey
2

環境変数を設定

.env.example をコピーして .env を作成し、AWSキーを設定します。

cp .env.example .env # .env を編集して AWS_ACCESS_KEY_ID などを設定
3

Docker で起動

migrate・初期アカウント作成まで自動で完了します。

docker compose up -d
4

ブラウザでアクセス

起動後、ブラウザで以下のURLを開いてください。

http://localhost:8000/

シード済みのデモアカウントでログイン — ユーザー tabata_hiroshi / パスワード Passw0rd!

5

tfstate を取り込む

S3バックエンドの場合はBucketとKeyを設定するだけ。ローカルの場合はファイルをアップロードします。

terraform state pull > infra.tfstate

詳しいセットアップ手順

IAMロールの設定・マルチアカウント対応・Slack通知の設定など、詳細はGitHubのREADMEをご覧ください。
